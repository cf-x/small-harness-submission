# 对抗式审查与修复记录

日期：2026-09-16。审查基线：`df05fbc`。用户要求：**“请你启用对抗式审查，优化项目”**。

## 审查方式

主审负责整合修复；两个独立审查任务分别从运行时/工具和 HTTP/配置/界面状态寻找反例。问题须有复现证据，修复后增加回归；未复现的猜测不计为缺陷。使用临时数据库和测试账户，未改动用户会话或对外披露凭证。

## 已确认并修复的问题

| 问题 | 修复前反例与影响 | 修复方式 | 回归证据 |
|---|---|---|---|
| 整除、取余提前舍入 | `99999999999999999999999999999%2` 返回 `-1`；接近 1 的小数整除 1 可能错误返回 1 | 对当前十进制操作数精确求整数商；余数计算保留足够中间精度；负号不提前舍入 | 大数、边界小数、正负除数和除零测试 |
| 零值格式化过量分配 | `0e-10000000` 输出虽为 0，过程中峰值分配约 20 MB；同步计算会阻塞事件循环 | 将零规范化，避免按无意义指数格式化或扩大运算精度 | 输出、取余及零除路径测试；峰值分配低于 1 MB |
| 长历史尾部无法取回 | 按全文关键词命中后固定返回前 1200 字符，尾部档案代号无法获取 | `read_history` 增加 `seq + offset` 分页，返回下一页位置与总长度；每页仍限制 1200 字符 | 分页重建完整原文、越界拒绝、会话隔离；真实模型在压缩后分页取回尾部代号 |
| 数值参数溢出进入自定义工具 | JSON `1e999` 被转换成无穷大，能通过 number Schema 并进入处理函数 | JSON 解析时拒绝非有限数值 | 正负溢出、NaN、Infinity 均拒绝且处理函数未执行；普通小数继续可用 |
| 畸形认证输入触发服务器错误 | 非 ASCII Bearer 令牌使字符串常量时间比较抛异常，返回 500 | 配置要求 ASCII 令牌，畸形请求返回 401 | 畸形请求拒绝后，合法令牌仍可访问 |
| 非有限超时绕过校验 | NaN、Infinity 能通过原正数检查，破坏运行时间上限 | 超时和相关预算必须是有限正数 | 三类超时分别验证 NaN、正负 Infinity |
| 活动执行被近期记录挤出 | 一个慢执行期间，连续入队并取消 21 条消息，运行中的执行从会话响应中消失，界面无法停止它 | 返回全部活动执行与最近 20 条已结束执行 | 真实异步慢任务配合 21 次入队取消，验证运行状态仍可见且可取消 |

## 保留的边界

本轮没有把试题项目扩成生产平台。仍采用单进程、只读内置工具、显式记忆和有损摘要；搜索继续明确标记为模拟。一般十进制运算仍受 28 位精度限制，整除/取余的精确性针对当前操作数，不恢复之前运算已舍入的信息。真实模型回归是有限样本验证，不证明所有提示下都能正确选择工具。
