# Small Harness 运行手册

## 基础循环

Agent 读取输入，模型自主选择直接回答或调用工具。Runtime 校验参数并执行工具，保存结果，再交给模型继续决策。

## 会话与记忆

每个窗口可以创建独立会话。恢复同一个 session_id 会继续原有历史。用户显式保存的记忆可设为当前会话或用户级；临时聊天不会自动写入用户级记忆。

## 工具

calculator 提供有限范围的十进制算术；search 使用模拟数据；read_docs 读取已注册文档；read_history 回查当前会话的历史。

## 测试事实

演示项目代号是 Cedar。演示预算上限为 800 元。演示项目包含三个验收项：工具闭环、会话隔离、压缩后追问。

这些是测试资料，不代表任何真实客户或业务。
